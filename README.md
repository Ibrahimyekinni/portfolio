# Portfolio

A small personal portfolio page, built for IFT 302: Web Application Development,
Department of Computer Science & AI, University of Ibadan.

No frameworks and no build step — three files and an image.

## Built with

- **HTML** for structure
- **CSS** for layout and theming: grid, flexbox, and custom properties
- **JavaScript** for behaviour, with no dependencies

## Features

- Light and dark theme, remembered between visits
- Tagline that types itself out on load
- Reading progress bar across the top of the window
- Navigation that highlights the section currently in view
- Sections that fade in as they are reached
- Single-column layout on phones
- Animation is skipped for anyone using a reduced-motion setting

## Files

| File | What it holds |
| --- | --- |
| `index.html` | Page content and structure |
| `style.css` | All styling; the colour palette sits in variables at the top |
| `script.js` | Theme toggle, typewriter, progress bar, scroll effects |
| `images/` | Profile photo |

## Running it

Open `index.html` in any browser. There is nothing to install.
